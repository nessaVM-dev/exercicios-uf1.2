### Missão 4: O Relatório

Entreguem as respostas:

1. O papel do JavaScript:
   Que diferença há entre o que o HTML, o CSS e o JavaScript fazem numa página? Deem um exemplo de algo que só o JavaScript consegue fazer.
   Resposta: [O HTML é o responsável pela estrutura da página, ou seja, define os elementos que existem, como textos, imagens, título e botões. O CSS é responsável pela aparência, como cores, os tamanhos, os espaçamentos e a organização visual. Já o JavaScript é responsável pelo comprtamento e pela interatividade, permitindo que a página reaja às ações do utilizador. Por exemplo, podemos utilizar JavaScript para criar um carrinho de compras que calcula automaticamente o preço total dos produtos, ou um menu que abre quando carregamos num botão. O HTML e o CSS não conseguem realizar essas funcionalidades sozinhos.]

2. `let`, `const` e `var`:
   Quando é que usam `let` e quando usam `const`? Porque é que não usamos `var`?
   Resposta: [Utilizamos let quando queremos criar uma variável cujo valor pode mudar durante o programa. Por exemplo, a quantidade de passageiros pode aumentar, por isso utilizamos let. Já const é utilizado para valores que não pretendemos alterar durante a execução do programa, como nome de uma loja ou o preço de um produto que permanece fixo. Não utilizamos var poque é uma formaantiga de declarar variáveis e permite, por exemplo, declarar a mesma variável várias vezes sem apresentar um erro. Isso pode causar problemas e tornar o código mais difícil de compreender. Por isso, seguimos a regra de utilizar const por defeito e let apenas quando o valor precisa mudar. ]

3. Tipos de dados:
   Qual é a diferença entre `3500` e `"3500"`? E entre `undefined` e `null`?
   Resposta: [A diferença entre 3500 e "3500" é que o primeiro é do tipo number, porque representa um número que pode ser utilizado em cálculos. O segundo é do tipo string, porque está entre aspas e representa um texto, mesmo que contenha números. A diferença entre undefined e null é que undefined significa que uma variável foi criada, mas ainda não recebeu nenhum valor. Já null significa que fomos nós que indicámos intencionalmente que não exesti nenhum valor naquela variável. Por exemplo, quando declaramos uma variável sem atribuir um valor, o JavaScript coloca automaticamente undefined. Quando queremos representar um valor vazio de propásito, podemos utilizar null.]

4. A armadilha do `+`:
   Porque é que `"10" + 5` dá `"105"`, mas `"10" * 5` dá `50`? Como se corrige a soma?
   Resposta: [O resultado de "10" + 5 é "105" porque o operador +, quando encontra um texto, pode juntar os valores em vez de realizar uma soma. Neste caso, o JavaScript transforma o número 5 em texto e junta-o ao texto "10". Já "10" * 5 dá 50 porque o operador de multiplicação converte o texto "10" num número para conseguir realizar a operação. Para corrigir a soma, podemos utilizar Number() para converter o texto num número antes de fazer o cálculo. Por exemplo, Number("10") + 5 resulta em 15.]

5. Ler erros:
   No detetive de erros, qual foi o erro mais difícil de encontrar e porquê?
   Resposta: [O erro que achei mais difícel de encontrar foi o da variável PrecoQuilo, porque o nome parecia correto, mas tinha a primeira letra maiúscula, enquanto a variável oroginal estava escrita como precoQuilo.
