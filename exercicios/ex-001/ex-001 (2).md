# Exercício Prático: A Viagem entre Ilhas

Hoje escrevemos as primeiras linhas de JavaScript: usámos a Console, ligámos um ficheiro `script.js` a uma página, guardámos valores em variáveis com `let` e `const` e conhecemos os tipos de dados primitivos. Agora é a vossa vez: vão criar o bilhete de uma viagem de barco entre ilhas e corrigir um ficheiro cheio de erros.

O vosso objetivo é escolher entre `const` e `let`, dar bons nomes às variáveis, reconhecer o tipo de cada valor, escrever frases com template literals e ler as mensagens de erro da Console.

Os ficheiros de que precisam estão na pasta [`ex-001/`](./ex-001/): `detetive.html` e `js/detetive.js`.

### Missão 1: Adivinhem o Tipo

1. Abram a Console (**Ctrl + Shift + J**; no Mac, **Cmd + Option + J**) numa página qualquer.
2. Para cada valor abaixo, **escrevam primeiro num papel** o tipo que acham que tem. Depois confirmem na Console com `typeof` (por exemplo, `typeof "Praia"`):
   - `"Praia"`
   - `3500`
   - `"3500"`
   - `12.5`
   - `false`
   - `"false"`
   - `undefined`
   - `` `Olá` ``
3. Ainda na Console, escrevam `"10" + 5`, `"10" * 5` e `Number("10") + 5`, e anotem os resultados. Vão precisar deles no Relatório.

_Quantos tipos acertaram à primeira? Os que falharam são os que têm aspas a enganar._

### Missão 2: O Bilhete de Barco

1. Na pasta `uf1.2-javascript`, criem a pasta `ex-001`, com o ficheiro `index.html` e a pasta `js` com o ficheiro `viagem.js`.
2. O `index.html` tem a estrutura base (`!` e **Tab** no VS Code), `lang="pt-PT"`, o título "A Viagem entre Ilhas", um `h1` com o mesmo texto e, no fim do `body`, `<script src="js/viagem.js"></script>`.
3. No `viagem.js`, criem as variáveis da viagem, escolhendo `const` ou `let` conforme o valor mude ou não ao longo do programa (leiam a missão toda antes de escolher):
   - `origem`: `"Praia (Santiago)"`;
   - `destino`: `"São Filipe (Fogo)"`;
   - `precoBilhete`: `3500` (escudos);
   - `passageiros`: `2`;
   - `lugaresLivres`: `120`;
   - `temCamarote`: `false`;
   - `numeroLugar`: sem valor (ainda não foi escolhido);
   - `observacoes`: vazio de propósito.
4. Mostrem na Console o `typeof` de cada variável (para `observacoes`, mostrem o valor).
5. Calculem o `total` (preço vezes passageiros), tirem os passageiros aos `lugaresLivres` (`lugaresLivres = lugaresLivres - passageiros;`) e deem ao `numeroLugar` o valor `27`.
6. Mostrem o bilhete na Console, uma linha de cada vez, com template literals:

```
Viagem: Praia (Santiago) -> São Filipe (Fogo)
Passageiros: 2
Lugar: 27
Camarote: false
Total: 7000 escudos
Lugares livres no barco: 118
```

7. Juntou-se mais um passageiro: aumentem `passageiros` em 1, **recalculem** o total, tirem mais um lugar livre e mostrem:

```
Com 3 passageiros, o total é 10500 escudos.
Lugares livres no barco: 117
```

_Organizem o ficheiro em secções com comentários, como o `script.js` da aula: 1. os dados da viagem, 2. os tipos, 3. o bilhete, 4. mais um passageiro._

### Missão 3: O Detetive de Erros

A Mercearia da Tia Lena tem um programa para o stock de arroz, mas ninguém o consegue pôr a funcionar.

1. Copiem para a pasta `ex-001` os ficheiros [`detetive.html`](./ex-001/detetive.html) e [`js/detetive.js`](./ex-001/js/detetive.js) (o `detetive.js` vai para a pasta `js`).
2. Abram o `detetive.html` com o Live Server e a Console. O `detetive.js` tem **seis erros**: quatro dão mensagem vermelha e dois não dão mensagem nenhuma, só resultados errados.
3. Corrijam **um erro de cada vez**:
   1. leiam a mensagem e o tipo de erro (`SyntaxError`, `ReferenceError`, `TypeError`);
   2. carreguem no link à direita (`detetive.js:NN`) para ver a linha;
   3. corrijam, guardem e vejam a mensagem seguinte.
4. Por cima de cada linha corrigida, escrevam um comentário com a mensagem de erro que aparecia ou, nos erros sem mensagem, com o que estava errado. Por exemplo: `// Erro 1: SyntaxError: ...`.
5. No fim, a Console deve mostrar, sem nenhuma linha vermelha:

```
Mercearia da Tia Lena: Arroz a 150 escudos o quilo.
Ficaram 35 sacos de arroz.
3 quilos custam 450 escudos.
boolean
```

6. Façam o ciclo do Git:
   - `git add .`
   - `git commit -m "Ficha 1: viagem entre ilhas e detetive de erros"`
   - `git push`

_Dica: os dois erros sem mensagem estão nas últimas linhas. Olhem para os resultados e perguntem-se: "isto faz sentido?"_

**Critérios de sucesso:**

- [ ] A pasta `ex-001` tem `index.html`, `detetive.html`, `js/viagem.js` e `js/detetive.js`.
- [ ] As variáveis que não mudam usam `const` e as que mudam usam `let`; não há nenhum `var`.
- [ ] Os nomes das variáveis estão em camelCase, sem acentos.
- [ ] O bilhete aparece na Console igual ao exemplo, e o total de 3 passageiros é 10500 escudos.
- [ ] A Console do `detetive.html` não mostra nenhum erro, e cada correção tem um comentário.
- [ ] O repositório `uf1.2-javascript` no GitHub tem a pasta `ex-001`.

A vossa pasta deve ficar assim:

```
uf1.2-javascript/
├── aula-01/
│   ├── index.html
│   └── js/
│       └── script.js
└── ex-001/
    ├── index.html
    ├── detetive.html
    └── js/
        ├── viagem.js
        └── detetive.js
```
